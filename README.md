# Mô phỏng Vật lí 6789

Bộ mô phỏng tương tác tiếng Việt cho KHTN lớp 6–9 (chương trình GDPT 2018). Mỗi mô phỏng là một file `index.html` duy nhất, chạy được trên điện thoại và máy chiếu.

- Cấu trúc: `lop-<6|7|8|9>/<ten-mo-phong>/index.html`
- Trang chủ: `index.html` (danh sách, lọc theo lớp, nút Nhúng và Đóng góp mô phỏng)
- Muốn đóng góp: bấm nút "Đóng góp mô phỏng" trên trang chủ để mở Issue và đính kèm file .html.

Giấy phép: MIT.
